# South-African-unemployment-analysis

# Unemployment Data Analysis (South Africa / Global)

## Overview
This project analyses unemployment trends and visualises data using Python.

## Tools Used
- Python
- Pandas
- Matplotlib / Seaborn
- Plotly (choropleth mapping)

## How to run
1. Clone repo
2. Install requirements:
   pip install -r requirements.txt
3. Open notebook:
   jupyter notebook

## Key Features
- Data cleaning and preprocessing
- Exploratory data analysis
- Choropleth map of unemployment rates
